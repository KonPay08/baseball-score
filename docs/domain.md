# Domain

## Domain Overview

少年野球1試合分の紙スコア表から打席結果を読み取り、選手別の打撃成績を集計する。

## Terminology

| Term | Meaning |
|---|---|
| Job | 1回のスコア表画像アップロードと、その解析・修正の単位 |
| 抽出結果（extracted） | AI（現在はサンプル）が読み取った生の記録。修正しても変更しない |
| 記録（record） | 抽出結果に担当者の修正を反映した記録。成績はこれから計算する |
| Cell | 1つの読み取り項目。`value`・`confidence`（high / low / unreadable）・`source`（extracted / corrected）を持つ |
| 要確認箇所（review item） | `confidence` が high でなく、まだ修正されていない Cell |
| 打席結果コード | `1B` `2B` `3B` `HR` `BB` `HBP` `K` `OUT` `SH` `SF` `E` `FC` `INT` |

## Business Rules

暫定ルール（NPBの記録の計算方法を参考にした。少年野球での適用はまだ合意していない）：

- 打席：結果が確定した打席の数。
- 打数：打席 − 四球 − 死球 − 犠打 − 犠飛 − 打撃妨害。失策出塁・野選は打数に含め、安打にはしない。
- 安打：単打・二塁打・三塁打・本塁打。
- 打率：安打 ÷ 打数。打数0の場合や未確認箇所がある場合は算出しない（`null`、表示は `-`）。
- 未確認・判読不能の Cell は0として扱わず、集計から除外する。その選手の成績は「暫定」（`complete: false`）とする。
- 修正された Cell は確定値とする。

## Important Constraints

- 読み取り精度を検証する前に、完全自動・無修正での利用を前提にしない。
- 成績計算はAPI側のコードで行い、AIに計算させない。

## Unknown Rules

- 少年野球に固有の記録ルール、チームの集計方針。
- 対象とする打撃・投手の成績項目（投手成績・自責点・防御率は未実装）。
- 打点の上限値（現在は入力検証を0〜4点としている）。
- 自チームのみを集計するか、両チームを集計するか（現在のサンプルは自チームのみ）。
- 対応するスコア用紙の形式と記法。
