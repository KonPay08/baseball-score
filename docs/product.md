# Product

## Background

少年野球チームでは試合中に紙のスコア表へ手書きで記録し、試合後に打率などを手作業で集計している。詳細は `PROJECT.md` を参照。

## Target User

紙のスコア表を使い、試合後の打率計算・選手別成績集計を担当する少年野球チームの関係者。

## User Problem

紙に記録した試合内容から、打率計算や選手別の成績集計を行う作業に手間がかかる（需要・作業時間は未検証）。

## User Goal

1試合分のスコア表を撮影してアップロードし、誤読を確認・修正するだけで、選手別の成績を確認できること。

## Core Value

手計算・転記の作業を「原本との照合と修正」に置き換え、集計の負担を減らす。

## Core User Flow

1. スコア表の画像を選び、「解析する」を押す（`POST /api/jobs`）。
2. 処理状態、抽出結果、要確認箇所（黄＝自信なし、赤＝判読不能）、打撃成績が表示される。
3. 原本と照合して値を選び、「修正を反映」を押す（`PATCH /api/jobs/:id/record`）。
4. 成績が再計算される。未確認の項目が残っている選手は「暫定」と表示される。

## Prototype Status

- 実装済み：アップロード、入力検証、ジョブ状態、抽出結果と要確認箇所の表示、修正、打撃成績の再計算。
- 未実装：AIによる実際の画像読み取り（AI未選定のため、どの画像でも固定のサンプル抽出結果を返す）、投手成績、画像・結果の永続化。

## Prototype Hypothesis

- 手書きスコア表から、成績集計に必要な情報を読み取れる。
- 誤読の確認・修正を含めても、従来の集計作業より負担が小さい。
- 担当者が次の試合でも利用したいと感じる。
